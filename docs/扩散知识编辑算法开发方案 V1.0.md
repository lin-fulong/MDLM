# 扩散知识编辑算法开发方案 V1.0

状态：开发规划，并同步记录截至 2026-10-22 的实现情况；本文件不代表算法已完整实现或实验已通过。主算法依据：[《最终逻辑 V1.0》](./最终逻辑%20V1.0.md)。数据与独立评价分别参照[数据集构建](./算法计划文档/01_扩散知识编辑数据集构建.md)和[外部大模型评测框架](./算法计划文档/03_外部大模型评测框架.md)。本方案只规划《最终逻辑 V1.0》中的默认主线，不把其他候选算法并入首版。

## 1. 目标、边界与开发顺序

目标是形成可复现的真实扩散模型知识编辑流水线：从编辑事实和本轮基准模型出发，固定兼容去噪状态，提取每层参考键矩阵 $K_\ell$ 与保持矩阵 $C_\ell$，求固定因子 $Q_\ell$，联合优化多层残差 $R_\ell$，合并实际权重，执行开发验收和回退，最后在独立问题上自由生成并评价。

**严格顺序：先交付并验收数据/矩阵提取脚本及其产物，再开发完整算法。**采样状态、$K$、$C$ 的脚本可以调用真实模型，但不更新模型权重，也不优化 $R$。矩阵产物通过质量门槛后，才进入 $Q$ 求解和编辑主循环。各阶段可以设计接口，不能用未验收的模拟矩阵宣称真实编辑闭环完成。

当前项目已经下载 Dream-v0-Instruct-7B、LLaDA-MoE-7B-A1B-Instruct、iLLaDA-8B-Instruct 和 LLaDA-8B-Instruct 四个基础模型。P0 已实现独立案例校验工具、可信 JSON/JSONL 读取、用途提取、token 对齐、统一模型接口、LLaDA-8B-Instruct 适配器和冒烟入口；8 项人工案例接口测试通过，当前 8 个非占位 P0 脚本均已完成代码审查。P0-02 已完成，P0-03～P0-05 仍缺正式数据清单、冻结配置以及真实 LLaDA tokenizer、8B 前向和重放证据。P1～P6 尚未开始，已有同名空文件仍只是占位文件。

数据集格式、字段完整性、质量、重复性、答案泄露和跨划分泄露由算法运行前的独立审核负责。`data/schema.py` 是按需手动调用的工具，不被数据读取、知识编辑或评估流程自动触发。算法运行时默认数据可信，只保留主体/答案 token 对齐、mask 位置和张量形状等计算必需处理。这一工程边界不改变后续知识编辑公式、训练策略、评价指标或结果计算方式。

| 阶段 | 交付重点 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0 | 运行配置、数据用途与模型接口冻结 | 真实 tokenizer、mask、模块和位置规则可核验 |
| P1 | 事实与状态数据脚本 | 每条事实有合法全 mask 初态和固定兼容状态 |
| P2 | **$K_\ell,C_\ell$ 矩阵提取脚本** | 全部目标层产物可重放、维度/有限性/半正定性通过 |
| P3 | 固定因子 $Q_\ell$ 求解 | 求解残差与数值检查通过 |
| P4 | 多层残差 $R$ 的真实模型联合优化 | 梯度、归一权重与候选前向核验通过 |
| P5 | 权重合并、开发验收、回退 | 接受/拒绝路径和前向等价通过 |
| P6 | 独立生成与评价 | 信息隔离、全量分母和结果追溯通过 |

依赖关系：`P0 → P1 → P2 → P3 → P4 → P5 → P6`。可在 P0 设计全部接口，但首版实现和验收按此顺序推进。可选第二轮刷新要等单轮闭环通过后再开发。

## 2. 贯穿各阶段的数据与模块契约

### 2.1 输入、用途和基准

- 编辑案例至少提供稳定 `case_id`、$q_i,s_i,r_i,a_i^*$、已核验的主体与短答案 token 对齐结果，以及编辑/开发/独立测试用途标记。按主体、源案例和依赖链隔离数据；多事实联合编辑时，$N$ 是本轮事实数，不是去噪状态数。
- 状态采集与矩阵提取使用本轮冻结基准 $\theta_b=\theta_{\mathrm{acc}}$；首次运行时 $\theta_b=\theta_0$。训练保持、开发编辑、开发保持、最终测试数据分别记录用途。$\theta_0$ 的模型版本与目标层初始权重必须长期保留，供 $G_{\mathrm{dev}}$ 和 $U$ 使用。
- 生成器只能接收问题、合法模板和生成配置。目标答案及裁判私有参考只能出现在编辑监督或评价侧，不得传入自主采样和最终自由生成调用。
- 配置清单固定模型/Tokenizer revision、模块白名单、采样器与去噪步数、窗口和 mask 规则、随机种子、数据版本、数值精度，以及之后各阶段的超参数。产物记录配置摘要和输入摘要，避免跨模型、跨轮或跨配置混用。

### 2.2 建议产物格式

建议以 `run_id/round_id` 建立不可变产物目录，包含一份 `manifest.json`、按事实索引的状态记录、按层索引的张量文件和一份校验报告。张量格式可选安全张量或其他可校验格式；具体库在 P0 确定。每个张量至少记录符号、层名、形状、dtype、列/行含义、事实顺序、模型与配置摘要、来源脚本版本及文件校验和。不要仅靠文件名推断列顺序。

| 产物 | 形状/索引 | 来源与使用边界 |
| --- | --- | --- |
| `states`、$\mathcal T_i$、$\mathcal M_{i,t}$ | 事实 → 完整输入状态 → 监督位置 | $\theta_b$ 自主采样；本轮优化中固定 |
| $K_\ell$ | $d_{\mathrm{in},\ell}\times N$，列序与事实清单一致 | $\theta_b$ 全 mask 初态的主体最后 token 输入；本轮固定 |
| $C_\ell$ | $d_{\mathrm{in},\ell}\times d_{\mathrm{in},\ell}$ | 目标模型保持输入的非负加权未中心化二阶统计；本轮固定 |
| $W_{0,\ell},W_{b,\ell}$ 的快照/引用 | $d_{\mathrm{out},\ell}\times d_{\mathrm{in},\ell}$ | 原始参照与本轮基准；禁止混淆 |
| $Q_\ell$ | $N\times d_{\mathrm{in},\ell}$ | P3 由同一轮的 $K,C,\lambda$ 求出；优化期间固定 |
| $R_\ell,\Delta W_\ell$ | $d_{\mathrm{out},\ell}\times N$；$d_{\mathrm{out},\ell}\times d_{\mathrm{in},\ell}$ | P4/P5 才生成；$\Delta W=RQ$ |

保存完整状态时包括实际 token IDs、mask 集合、位置 IDs、注意力条件、模板/窗口标识和影响前向的其他输入；避免仅存可见文本。长期归档可保存重放所需的确定性字段与摘要，验收时必须证明重放 logits 一致。参数绑定/共享存储按唯一底层参数识别，防止重复写入。

### 2.3 首版必须提前冻结的选择

| 选择 | P0 要作出的决定 |
| --- | --- |
| 模型适配 | 首个目标模型、预测位置/logit 对齐、模块名称和 FFN 输出线性层输入捕获点；不能套用另一模型的偏移规则 |
| 数据范围 | 先选小型人工核验 gold 与单事实/少量联合事实；明确 MQuAKE 多编辑依赖和每题独立真值 |
| 状态采样 | 不重新掩码的受控短答案窗口、初态、去重键、采样预算和失败诊断 |
| 保持统计 $C$ | 保持语料、mask 上下文、读出/采样位置、非负 $\omega$、聚合与尺度；不默认中心化或强制 $\sum\omega=1$ |
| 保持训练 | 是否启用 $L_{\mathrm{keep}}$、其数据/读出位置/归一权重；若 $\beta=0$，仍执行开发保持验收 |
| 数值和验收 | $\lambda_\ell>0$、$\rho_\ell>0$、优化预算/检查点、$\epsilon,\delta,\tau_G,\tau_U$、公共 $\alpha$ 列表及求解/等价容差；数值阈值应在开发集确定并冻结 |
| 最终评价 | 自由窗口、种子、独立问题、裁判版本及失败/不确定覆盖率口径 |

没有文档给出可直接照搬的全部数值超参数。P0 记录所选值、依据和适用实验；需要调参时更新配置版本，不能在看到独立测试结果后逐例改门槛。

## 3. P0：运行前契约与最小模型适配

**任务**

1. 确认代码与数据的实际仓库/路径、模型权重许可和版本、硬件预算；建立配置文件、运行清单和按用途隔离的数据视图。
2. 实现或规划统一模型适配接口：真实 tokenizer 与模板编码、全 mask 答案窗口构造、一步前向的 logits 位置映射、受控自主去噪、目标模块输入捕获、目标权重读取与恢复。先用原模型只读调用核对接口。
3. 使用真实 tokenizer 定位主体最后 token 和答案全部位置 $\mathcal A_i$，核对 mask ID、特殊 token、前导空格及多 token 答案的实际 token IDs。对齐失败应作为无法构造模型输入的计算错误报告；数据质量问题及不合格案例原因由运行前独立审核记录。
4. 明确目标模块的实际调用次数、输入/输出维度、权重方向、偏置、共享参数；建立模块白名单。训练态随机行为和精度策略应固定。

**产物与门槛**：版本化配置、模型适配说明、事实用途清单、token/位置对齐报告及一条可重放的全 mask 前向记录。未通过实际 tokenizer 和模块输入定位，不进入状态/矩阵提取。

**当前进展（2026-10-22）**：`data/schema.py` 已完成 P0-02，作为独立手动校验工具；`data/readers/json_cases.py`、`data/validation/alignment.py`、`model/base.py`、`model/registry.py`、`model/adapters/llada_8b_instruct.py` 和 `util/smoke_p0_llada.py` 已覆盖 P0-03～P0-05 的主要代码路径。当前接口测试共 8 项并已通过。P0 尚未退出，因为 P0-01 配置未冻结，正式数据清单未建立，真实 tokenizer、8B 前向、目标层输入捕获和重放尚无验收报告。

## 4. P1：状态采集与监督数据脚本

建议脚本职责：`prepare_edit_cases` 读取已经独立审核的数据并冻结案例用途视图；`collect_denoise_states` 从本轮 $\theta_b$ 全 mask 初态自主采样并保存每次前向前完整输入；`filter_compatible_states` 对完整模型状态去重，按公式（1）筛选；`validate_state_artifacts` 生成覆盖和重放报告。这里的状态去重、兼容筛选和重放验证属于算法状态构造，不是输入数据集的格式、质量、重复性或跨划分泄露检查。

**执行细节**

1. 构造受控短答案窗口；模型采样时不注入新答案、不用目标 token 指定揭示路径。保存全 mask 初态、自然轨迹、冲突状态和终态；仅兼容且至少还有一个 mask 的状态进入 $\mathcal T_i$。
2. 对每个状态建立 $\mathcal M_{i,t}\subseteq\mathcal A_i$；已揭示答案位置必须逐 token 等于目标答案。去重依据完整实际输入与影响前向的条件，不按可见文本去重。
3. 预计算或记录公式（2）（3）的权重 $w_{i,t,j}=1/(N|\mathcal T_i||\mathcal M_{i,t}|)$。微批重放以后仍按此全局权重聚合，不能把全部状态直接平均。

**产物与门槛**：固定状态数据、兼容/冲突/终态计数、每事实状态数与权重核验报告。每条合法事实应保有非空全 mask 初态；每事实权重和应为 $1/N$，全局权重和为 1；随机抽取状态重放应得到一致输入与有限 logits。失败案例保留诊断，不能静默从预定统计分母消失。

## 5. P2：先完成 $K$、$C$ 矩阵提取脚本

这是进入完整算法开发前的**关键交付阶段**。建议将 `extract_reference_keys`、`extract_keep_statistics` 与 `validate_matrix_artifacts` 分开，使来源、采样配方和质量问题可独立排查。脚本均只读 $\theta_b$，不求 $R$，不写回权重。

### 5.1 提取 $K_\ell$：公式（4）

对每条事实使用 P1 固定的**全 mask 初态**，在每个目标 FFN 输出线性层的实际输入端捕获主体最后一个 token 位置的激活 $k_{i,\ell}^{\mathrm{ref}}$。按冻结的事实顺序逐列堆叠成 $K_\ell=[k_{1,\ell}^{\mathrm{ref}},\ldots,k_{N,\ell}^{\mathrm{ref}}]$。多个兼容状态用于损失监督；默认每事实每层只取这一列参考键。不要用答案 embedding、注意力 Key、模块输出或其他去噪状态代替。若捕获点在单次前向被调用多次，须按模型结构明确对应调用并验证位置。

验收：全部目标层形状为 $d_{\mathrm{in},\ell}\times N$；列与 `case_id` 一一对应；激活有限；重复提取在固定精度/确定性设置下达到容差；抽查捕获值与该层真实输入一致。

### 5.2 提取 $C_\ell$：公式（5）

在目标扩散模型的保持输入与 mask 上下文中捕获**同一目标线性层输入** $u_{\ell,m}$，依据 P0 冻结的非负权重累加 $C_\ell=\sum_m\omega_{\ell,m}u_{\ell,m}u_{\ell,m}^{\top}$。记录样本来源、mask 配方、位置、各组计数、权重总量和尺度。使用流式或微批外积累计，避免保存所有激活；累计精度和内存策略按实际维度确定。$C$ 是未中心化二阶统计，不能无说明地改为去均值协方差，也不能把开发保持输入混作训练统计而仍称独立。

验收：每层 $C$ 为输入维方阵、有限、对称（在预定数值容差内）且数值上半正定；对抽样向量 $v$ 检查 $v^\top Cv\geq -\mathrm{tol}$，并用小批直接外积重算核对。检查 trace、对角尺度、最大/最小特征值或可行的谱估计；异常尺度先查采样/权重，不在脚本里无记录地重新缩放。

### 5.3 本阶段退出条件

形成完整的 `states + K + C + W_0/W_b 引用 + manifest + QA` 产物包。报告明确每层 $d_{\mathrm{in}},d_{\mathrm{out}}$、事实顺序、状态覆盖、矩阵采样数、数值检查和重放结果。**没有经过真实模型提取并通过校验的 $K,C$，不得启动 P3–P5 的真实编辑实验。**若本轮基准改变，P1/P2 的产物失效，应重新采样并提取。

## 6. P3：固定因子 $Q$ 与数值求解

读取**同一轮、同一模型、同一层**的 $K_\ell,C_\ell$ 与预定 $\lambda_\ell>0$，构造 $H_\ell=C_\ell+K_\ell K_\ell^\top+\lambda_\ell I$，解 $H_\ell X_\ell=K_\ell$，设 $Q_\ell=X_\ell^\top$；不显式求逆。先尝试适合对称正定矩阵的分解，并根据预先规定的失败策略处理数值异常。检查对称性、分解结果、有限性和相对残差 $\|HX-K\|/\max(\|K\|,\epsilon)$；记录条件尺度、dtype、耗时和内存。不得为通过测试而在运行中悄悄改变 $\lambda$。

产物为每层固定 $Q$ 和求解报告，形状必须是 $N\times d_{\mathrm{in}}$。用小型矩阵核对 $RQ$ 满足公式（7）的正规方程；$QK$ 一般不等于单位阵，不能把软拟合误差视作求解器失败。

## 7. P4：真实候选网络中的多层残差联合优化

**实现顺序**：先做单层单事实、单状态的最小可微前向；核验后扩展到多状态、多事实、多层。冻结 $\theta_b$、状态、$K,C,Q$，只将各层 $R_\ell\in\mathbb R^{d_{\mathrm{out},\ell}\times N}$ 设为可训练参数，初值为零。候选模块对**全部实际调用位置**计算 $W_bk+b+R(Qk)$，所有目标层在同一个前向网络中生效；不能仅在主体位置插入残差，也不能把后层输入 $k$ 预存为固定值。冻结基准权重不应切断经过它的反向传播。

按公式（10）计算 $J(R)=F(\theta(R))+\beta L_{\mathrm{keep}}(\theta(R))+\tfrac12\sum_\ell\rho_\ell\|R_\ell\|_F^2$。编辑项严格按事实、状态、剩余 mask 的三级归一；可选保持训练项使用与开发保持分开的固定输入，参照 $\theta_0$。每个完整优化步逐微批累积数据梯度，残差正则仅加一次；统一检查有限性后更新所有层。梯度应符合公式（12），并在小例中与有限差分或独立求导核对。不得为节省显存而切断同一次候选前向中的跨层梯度。

在预定检查点选择有限、非零且 $J(R^*)<J(0)$ 的候选；若无合格候选，本轮失败，不进入写回。记录每项损失、有效监督位置数、残差/增量范数、梯度范数、优化器状态与峰值资源。$R^*$ 是有限预算内选出的候选，不声称整网全局最优。

## 8. P5：实际写回、开发验收与回退

由 $R^*$ 计算 $\Delta W_\ell=R_\ell^*Q_\ell$；$V_\ell^*=W_{b,\ell}K_\ell+R_\ell^*$ 仅作参考键上的辅助诊断，不直接写入模型。记录公式（14）的软拟合误差 $R_\ell^*(Q_\ell K_\ell-I_N)$，不把它误称为语义错误。对同一输入与同一 $\alpha$，先核对临时因子前向和实际合并前向的目标层输出及 logits 在精度容差内一致，再关闭因子分支。

按预定有限正序列依次尝试公共 $\alpha$；**每次都从 $W_b$ 重建** $W_{\alpha,\ell}=W_{b,\ell}+\alpha\Delta W_\ell$，不得在上一试步的权重上累加。每个候选同时检查：

1. $F_{\mathrm{dev}}(\theta_\alpha)\le F_{\mathrm{dev}}(\theta_b)-\delta$，在固定开发编辑输入上评估；
2. $G_{\mathrm{dev}}(\theta_\alpha)\le\tau_G$，同一开发保持输入/位置上计算相对**最初模型 $\theta_0$**的完整词表 KL；
3. $U(\theta_\alpha)\le\tau_U$，按公式（17）计算相对**最初权重 $W_0$**的净累计变化；
4. 数值有限、模块参数完整、逐层增量与前向一致性通过。

首个按既定顺序通过全部条件的候选成为 $\theta_{\mathrm{acc}}$；不通过即完整恢复本轮 $\theta_b$ 后试下一个 $\alpha$；全部失败则保留上一次接受模型并终止外轮。验收报告逐项保存数值与拒绝原因，不用总分互相抵消。首版默认单轮；若之后实现可选刷新，接受后须以新 $\theta_b$ 重新执行 P1–P4、$R=0$，但 $\theta_0/W_0$ 参照不变。

## 9. P6：固定最终模型的独立生成与评价

固定 $\theta_{\mathrm{final}}=\theta_{\mathrm{acc}}$，关闭所有临时因子分支，在未参与训练或开发选择的问题和新种子上按统一自由窗口重新去噪。推理输入不含目标答案、别名或裁判参考；不按短答案长度逐例缩短预算，不指定正确揭示路径。保存完整原始回答与预定 final-answer 提取结果。

评价层分别报告候选接受率、固定短答案诊断、自由回答目标事实正确率、完整性、保持与传播表现；外部裁判只评价最终完整回答，不参与 $R$ 梯度。先用人工校准集验证裁判，再冻结规则。拒绝、回退、生成失败、裁判失败和不确定均保留在预定端到端分母中，并单列覆盖率。验收检查生成侧信息隔离：仅改变私有参考答案，真实模型输入 token 与解码参数应完全不变。

## 11. 最小验收路线与完成定义

按以下规模逐级推进：**单事实/单层/单状态 → 多状态 → 多事实/单层 → 多层联合 → gold 集单轮 → 独立测试**。前四级验证实现正确性，gold 集用于确定配置与检查真实运行，独立测试只在配置冻结后执行。矩阵脚本的完成定义是 P2 的真实产物和 QA 全部通过；算法代码的完成定义是 P3–P5 能在真实模型上产生可接受或可解释回退的结果；研究效果的完成定义还需要 P6 独立生成证据。任一阶段的“通过”都不代替下一阶段。

优先检查的错误：答案/token 位置偏移、旧答案注入轨迹、状态只按文本去重、$K$ 捕获成模块输出、$C$ 误用中心化协方差、$Q$ 显式求逆或混轮、微批损失归一改变、多层梯度被截断、只在主体位置加因子、共享参数重复写入、试步累加、以 $\theta_b$ 代替 $\theta_0$ 计算保持漂移、用短答案损失代替自由生成成绩。

最终交付应包含：版本化配置与数据清单、P1/P2 提取脚本及真实产物、P3–P5 算法实现与验收记录、P6 独立生成及评价报告、可复现运行说明。整个流程应能从输入版本和种子追溯每个状态、矩阵、候选、接受或回退决定。
