# 模型方案文档

副标题：短答案监督的掩码扩散知识编辑研究方案。

统一版本：2026-09-23 · 三文档汇编版。状态：候选研究方案，未完成真实模型效果验证。

本套文档分工：《01 算法文档》规定执行步骤和验收；《02 自回归模型迁移文档》规定各编辑器的原式与扩散接口；本文说明研究目标、模块作用、技术逻辑、实验计划和局限。三份文档统一采用“以实际候选权重反馈优化残差，保留已有闭式写回结构”的主线。早期输出梯度目标与全状态流式方案保留为对照，不与当前主算法混用。

## 1. 要解决的问题与当前阶段

项目最终目标是：给定问题所确定的主体与关系，以及一个短的新答案，将该事实写入掩码扩散语言模型的参数；模型之后在不接收答案提示的情况下，通过多步去噪自由生成包含新事实的完整回答。

当前先验证可实现的基础链路：短答案监督能否产生有效内部目标，能否经闭式更新写入权重，能否提高独立生成的完整短答案成功率。训练阶段使用与短答案 token 数匹配的受控窗口，已知监督位置；长窗口、未知答案位置与自由措辞是后续迁移评价，不作为已经解决的训练问题。不会用完整长答案监督替代短答案输入。

被迁移的是自回归知识编辑方法的求解机制，并不是把一个自回归语言模型直接改造成扩散语言模型。被编辑对象应当是已有的掩码扩散语言模型；层和模块配置需要在该模型上确定。

### 1.1 三个功能的落实方式

| 用户关心的功能 | 本方案如何实现 | 当前不能直接推出的结论 |
| --- | --- | --- |
| 短答案监督最终输出 | 用短答案 token 的损失优化候选权重所决定的残差；合并后重新自由生成 | 受控位置损失下降不保证任意长回答语义正确 |
| 闭式解包含隐藏状态信息 | 键来自真实模块输入；残差经过真实网络输出反馈；保持项来自扩散隐藏激活 | 残差本身不是完整隐藏状态，也不携带全部去噪轨迹 |
| 自回归编辑方法迁移到扩散模型 | 保留 ROME、MEMIT 等求解核，重建扩散域键、目标残差与保持统计 | 不能只加时间下标，也不能照搬全部原模型配置 |

### 1.2 正确的状态概念

扩散 Transformer 每一次前向都有层内隐藏表示、注意力和 FFN 激活。标准无缓存采样主要把更新后的 token/mask 序列送入下一步，而不是直接递归传递上一步的隐藏向量。因此，“没有跨步递归隐藏状态”不等于“没有隐藏表示”。固定的一次权重编辑会在后续多次前向中反复起作用；去噪步数也不必等于精确网络前向次数。

## 2. 总体模块与信息流

| 模块 | 输入与输出 | 作用 |
| --- | --- | --- |
| 数据与模块定位 | 问题、短答案、待编辑模型；输出合法样本和编辑模块集合 | 保留主体—关系条件，确认维度、位置和权重方向 |
| 真实状态采集 | 全 mask 初态与模型自主采样；输出完整前向输入状态 | 引入扩散中的状态变化，不向轨迹填入新答案 |
| 键与保持统计 | 参考状态、独立保持数据；输出键、二阶统计及方法约束 | 定义闭式更新可使用的方向与局部保持代价 |
| 残差优化 | 固定状态与求解器；输出各层优化残差 | 让短答案决定能经真实权重实现的目标变化 |
| 闭式写回 | 已确定残差；输出模块权重增量 | 合并固定参数修改，移除临时计算路径 |
| 验收和评价 | 实际合并模型；输出接受结果和独立评测 | 区分目标拟合、生成成功、保持能力和长句语义 |

主线先用一个批量 MEMIT 求解核作为实现入口，再对照 ROME/EMMET、AlphaEdit 等求解器。这里的优先级是工程建议，不表示任何方法在本项目上已经优于其他方法。

## 3. 从短答案到内部目标

### 3.1 层内表示与参考键

\[
W_{b,\ell}\in\mathbb R^{d_{o,\ell}\times d_{i,\ell}},\qquad
K_\ell=[k_{1,\ell},\ldots,k_{N,\ell}],\qquad
R_\ell\in\mathbb R^{d_{o,\ell}\times N}.
\]

符号释义：\(\ell\) 为待编辑模块；\(W_{b,\ell}\) 为本轮冻结的基准权重；\(d_{o,\ell},d_{i,\ell}\) 为其输出、输入维度；\(K_\ell\) 为按列排列的参考键矩阵；\(k_{i,\ell}\) 为事实 \(i\) 的参考键；\(N\) 为事实数；\(R_\ell\) 为待优化残差。本文未标下标 D 的键和统计均在扩散模型中提取；\(\mathbb R\) 表示实数空间。

默认每条事实在全 mask 初态、主体最后一个 token 的 FFN 输出线性层输入处取一个参考键；主体必须在问题中有明确对齐。若模型或任务无法使用该位置，应在实验前固定另一种取键规则，不能在测试后逐例挑选。键是线性层输入激活，不是注意力 Key；目标也不是直接使用答案的词嵌入。

多个去噪状态用来监督同一批残差，不要求每个状态都增加一列参数。参考键固定，但真实候选前向中的激活并不冻结，尤其后层激活会随前层候选更新变化。

### 3.2 短答案监督与状态权重

\[
\begin{aligned}
L_{i,t}(\theta)&=-\frac1{|\mathcal M_{i,t}|}
\sum_{j\in\mathcal M_{i,t}}\log p_{\theta,j}(a^*_{i,j}\mid x_{i,t}),\\
F(\theta)&=\sum_{i=1}^{N}\sum_{t\in\mathcal T_i}w_{i,t}L_{i,t}(\theta),\qquad
w_{i,t}=\frac1{N|\mathcal T_i|}.
\end{aligned}
\]

符号释义：\(L_{i,t}\) 是事实 \(i\)、状态 \(t\) 的短答案掩码损失；\(\theta\) 是候选模型；\(\mathcal M_{i,t}\) 是仍被 mask 的非空答案位置集；\(j\) 为位置编号；\(a^*_{i,j}\) 是目标 token；\(x_{i,t}\) 是固定的真实输入状态，包含问题及必要的时间、位置、注意力条件；\(p_{\theta,j}\) 是该位置原始预测分布；\(F\) 是固定状态平均损失；\(\mathcal T_i\) 是兼容状态集合；\(w_{i,t}\) 为归一权重；\(N\) 为事实数；\(|\cdot|\) 为集合大小。

兼容状态必须仍有 mask，且已经揭示的答案 token 与目标一致；每个非空目标的全 mask 初态总被保留。短答案只用于损失、筛选和评价，不写入采样输入。不兼容状态和终态保留诊断，并报告筛选覆盖率。这个筛选不能修复所有错误路径，特别是采样器不允许重掩码时，已经锁定的错误 token 不能由后续 mask 损失直接纠正。

### 3.3 通过实际候选权重优化残差

\[
\begin{aligned}
\Delta W_\ell(R_\ell)&=\mathcal S_{m,\ell}(R_\ell;K_\ell,\Omega_\ell),\\
\theta(R)&=\theta_b\oplus\{\Delta W_\ell(R_\ell)\}_{\ell\in\mathcal L},\\
J(R)&=F(\theta(R))+\beta L_{\mathrm{keep}}(\theta(R))
+\frac12\sum_{\ell\in\mathcal L}\rho_\ell\|R_\ell\|_F^2,\\
R^*&\approx\underset{R\in\mathcal R_m}{\operatorname{argmin}}J(R).
\end{aligned}
\]

符号释义：\(\mathcal S_{m,\ell}\) 是方法 \(m\) 在模块 \(\ell\) 的更新映射；\(K_\ell\) 是固定扩散键，\(\Omega_\ell\) 是固定保持统计、投影或历史信息；\(\Delta W_\ell\) 是候选增量；\(\theta_b\) 是基准模型；\(\oplus\) 表示仅替换指定权重；\(\mathcal L\) 是编辑模块集合；\(R\) 表示各层残差的集合；\(F\) 为短答案损失；\(L_{\mathrm{keep}}\) 为独立保持输入上的分布保持损失；\(\beta\ge0\) 为其权重；\(\rho_\ell>0\) 为各层残差正则；\(\|\cdot\|_F\) 为 Frobenius 范数；\(\mathcal R_m\) 是该方法允许的残差空间；\(R^*\) 为有限步优化结果，星号不表示全局最优。

本轮内固定状态、键、保持统计和投影，冻结模型基准权重，只优化残差。所有编辑模块在同一个候选前向中同时生效。对任何会改变输出的投影或后处理，训练候选与验收模型必须一致；无法稳定求导的后处理作为显式外部变体，后处理后重新验收。

保持损失使用与编辑目标无直接冲突的数据。若为了对照令保持损失权重为零，仍须执行独立保持验收；更改保持数据或权重必须在实验设置中说明。

### 3.4 有效目标与最终写回

\[
V^*_\ell=W_{b,\ell}K_\ell+R^*_\ell,\qquad
W'_\ell=W_{b,\ell}+\mathcal S_{m,\ell}(R^*_\ell;K_\ell,\Omega_\ell).
\]

符号释义：\(V^*_\ell\) 是与基准模块线性输出处于同一空间的有效目标；\(W_{b,\ell}\) 为基准权重；\(K_\ell\) 为参考键；\(R^*_\ell\) 为优化残差；\(W'_\ell\) 为候选更新后权重；\(\mathcal S_{m,\ell}\) 为选定求解器，\(\Omega_\ell\) 为其固定配置。偏置保持不变时，该目标定义对应去偏置的线性输出。

等式中的目标定义始终成立，但软约束求解器不保证最终权重在所有参考键上精确达到该目标。闭式的是“给定残差后的权重写回”，不是短答案到参数的全局闭式最优解。

## 4. 默认批量求解核及其意义

\[
\begin{aligned}
H_\ell&=C_\ell+K_\ell K_\ell^\top+\lambda_\ell I,\\
Q_\ell&=K_\ell^\top H_\ell^{-1},\qquad
\Delta W_\ell=R^*_\ell Q_\ell,\\
(W_{b,\ell}+R_\ell Q_\ell)k
&=W_{b,\ell}k+R_\ell(Q_\ell k).
\end{aligned}
\]

符号释义：\(C_\ell\) 为含保持尺度的对称半正定扩散二阶统计；\(K_\ell\) 为固定参考键；\(\lambda_\ell>0\) 为本方案显式加入的 ridge 正则；\(I\) 为输入维度单位阵；\(H_\ell\) 为正定系数矩阵；\(Q_\ell\) 为固定右因子；\(R_\ell\) 为正在优化的残差，\(R^*_\ell\) 为最终候选残差；\(\Delta W_\ell\) 为更新；\(k\) 为当前候选网络在任意实际调用位置的输入激活；\(W_{b,\ell}\) 为基准权重；\(\top\)、\(^{-1}\) 为转置、逆。

这是带明确 ridge 项的 MEMIT 核变体，不能把附加正则说成 MEMIT 原式原封不动的组成。实现时求解正定线性系统得到右因子，不显式计算逆矩阵。因子形式应覆盖该模块的全部调用位置；只在主体位置注入向量不等价于真实权重编辑。

固定右因子时，残差优化也可理解为固定右侧基的低秩参数优化。这一联系应写入论文定位；本方案既有梯度优化，又有解析写回，不能称为完全无梯度编辑。

## 5. 多事实、多状态、多层与内存

每条事实默认一列残差，多状态共享这些参数。多事实通过同一候选模型的平均损失联合优化；每层维护自己的参考键和残差，因此允许不同输入维度。多层同时作用于真实前向，利用实际网络反馈处理层间影响；这改变了原 MEMIT/PMET 的顺序剩余目标分配，应称基于原求解核的扩散变体。

已有流式方案仍有价值：当每个状态的目标残差已经固定时，可以累加残差—键外积和键二阶矩，最后求一次软约束解；详见算法文档中的备选流程。它与当前“残差随优化步改变”的主线不能混为同一趟累加。固定目标可单次累加，迭代目标需更新相关统计或使用固定求解因子。

以内存示例说明取舍：输出维度 4096、输入维度 14336、FP32、500 条事实时，每层残差约 7.81 MiB，固定右因子约 27.34 MiB；5 层两项合计约 175.78 MiB。每条事实的 10 个状态若只参与小批监督，不必把这两项扩大 10 倍。模型激活、优化器、权重和求解工作区另计，不能据此推断总显存。

相同维度下，单层稠密交叉统计约 224 MiB，键二阶统计约 784 MiB；流式累计虽然不随状态数线性增长，也未必比少量键和因子更省内存。先逐层准备求解器并释放临时大矩阵，再进行小批残差优化。每批反向后释放计算图，同一优化步内保持残差不变，按全局权重累计梯度。

## 6. 验收、评价与实验安排

### 6.1 明确区分开发验收与最终测试

训练状态用于优化；开发改写与开发保持输入用于候选选择、阈值和步长验收；独立测试改写、随机种子和保持任务仅用于最终报告。用于选模型的样本不能再被称为完全独立的最终测试证据。

验收同时检查：实际合并后的短答案目标是否改善，保持分布漂移是否受控，累计参数变化是否在预定范围，以及数值是否有限。全部失败则返回上一个已接受模型。默认一轮；可预先设定最多刷新一次，刷新时重新采样和重建键、统计，不能重复应用旧残差。

### 6.2 三层效果评价

| 评价层次 | 必须报告的内容 | 避免的混淆 |
| --- | --- | --- |
| 基础链路 | 候选接受率、完整短答案生成、提示改写泛化 | 局部损失下降不等于完整生成成功 |
| 状态与保持 | 状态保留率、不同噪声阶段表现、同主体其他关系、历史事实和一般能力 | 筛选后成功不等于全部轨迹成功 |
| 长窗口语义 | 目标事实表达、否定与矛盾、完整性、额外断言 | 实体出现或更长回答不等于事实正确 |

长回答的大模型裁判接收问题、目标事实和完整输出；反事实编辑以给定目标事实为本次标准。要求返回判定和原文证据。额外断言没有证据时标为待核验，不据短答案直接判真。固定裁判版本和规则，用人工样本检查一致性。裁判是评价工具，不自动产生可微的残差训练目标。

### 6.3 最小实验矩阵

1. 单事实、单层、全 mask：验证参考键、候选因子、合并权重和短答案链路。
2. 同一求解器下比较全 mask 与多个真实状态，匹配优化步数或另外报告计算量。
3. 比较局部隐藏干预目标、早期输出梯度目标、当前实际候选权重残差目标，匹配保持监督和层配置。
4. 在相同数据协议下比较 MEMIT 核、ROME/EMMET、AlphaEdit；不要把不同方法残差互换后声称各自得到最优结果。
5. 逐步扩展多事实和多层，再测试 500 条、10 个状态、5 层这一讨论规模，报告显存峰值、耗时和失败原因。
6. 最后测试长窗口、不同去噪预算和可选第二轮，冻结开发选择后使用独立测试集。

## 7. 主要风险与论文可主张的范围

1. 短窗口的已知位置监督尚未解决长回答中的未知位置、同义表达及整句语义。
2. 一个参考键的更新容量可能不足；增多状态键又会增加相关性、冲突和计算成本。
3. 旧模型状态与编辑后状态分布不同，固定轨迹目标只是代理。
4. 多层网络是非线性的，逐层解析解不能构成全网解析最优性证明。
5. 保持统计与子空间只约束有限代理，不证明所有旧知识不变。
6. 冻结右因子的残差训练与低秩参数优化有关，需要避免将重参数化本身当作充分创新。

已有工作已研究扩散模型中的知识编辑，见[Knowledge Editing for Masked Diffusion Language Models](https://arxiv.org/html/2606.03924v2)。本项目应验证实际候选权重反馈、多状态监督和不同闭式核之间的作用关系；已有论文结果不能替代本项目实验。

现阶段可主张：提出了维度明确、可实现的目标构造与求解器适配接口，并完成部分小型线性代数核验。不能主张：已经实现 500 条事实的有效批量编辑、已经解决自由长句语义、获得全局闭式解或已经证明优于已有方法。

## 8. 三份文档的共同约定

新方案不沿用早期梯度目标算法的一阶下降结论；是否接受候选由真实合并模型决定。默认键组织为每事实一列，默认多层组织为同一基准上的联合残差优化；全状态键、原方法顺序分配、后处理和第二轮均为显式可选项。数学符号在各展示公式后就近解释；公式编号在各文档内独立，不与历史版本的编号混用。

研究依据与各方法出处集中列于《02 自回归模型迁移文档》。执行、停止、回退和日志要求见《01 算法文档》。三份文档提供的是研究规格，真实模型验证状态保持为“待完成”。
