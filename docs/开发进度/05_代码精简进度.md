## 保持统计与公式（5）的对应

核心计算为：

$$
C_\ell=\sum_m\omega_{\ell,m}u_{\ell,m}u_{\ell,m}^{\top},
\qquad \omega_{\ell,m}\ge0.
\tag{5}
$$

实现先令 $v_m=\sqrt{\omega_m}u_m$，再按批次累计 $C\mathrel{+}=V^\top V$，其中 V 的每行是一个 $v_m^\top$。沿用先以 float64 吸收权重、再转换为配置累计精度的计算方式，零权重项不参与乘法；不去均值、不归一化、不添加 ridge。原有分块上三角复制继续保留，以保持 C 的计算结果一致。

已移除的内容包括初始化与输入的自定义检查、样本统计计数、独立坐标外积、trace 核对、随机正交投影、特征值检查、diagnose 方法、所有诊断字段，以及提取阶段的两次额外前向。

保持输入、掩码上下文和捕获位置仍由输入准备与模型适配器确定。keep_matrices 只接受 accumulation_dtype、storage_dtype、device、batch_keep 四个配置参数，返回（模块名，C）；旧 QA 种子、投影数量、重放与检查容差等参数已移除。

## 固定写回因子：功能、函数与公式

`MDLM/writeback.py` 接收每层的 K、C 和正则系数 λ，预先求固定右因子 Q；后续由其他模块优化 R，并通过 ΔW=RQ 形成权重增量。本文件不优化 R，也不写入模型权重。

对照《最终逻辑 V1.0》第五节，原实现和精简后的核心求解均与公式（6）～（9）对齐：

| 公式 | 数学内容 | 代码中的对应作用 |
| --- | --- | --- |
| （6） | $\Phi(D\mid R)=\tfrac12\lVert DK-R\rVert_F^2+\tfrac12\operatorname{tr}(DCD^\top)+\tfrac\lambda2\lVert D\rVert_F^2$ | Q 的推导依据；不在此文件中反复优化 D 或 R |
| （7） | $DH=RK^\top$，$H=C+KK^\top+\lambda I$ | 复制 C 后依次加入 KKᵀ 与 λI，保留原计算顺序 |
| （8） | $\xi^\top H\xi\ge\lambda\lVert\xi\rVert_2^2>0$ | 在 C 对称半正定、λ>0 的算法前提下采用 Cholesky 分解 |
| （9） | $HX=K$，$Q=X^\top$，$\Delta W=RQ$ | 解线性系统并返回 Q，不显式求逆；ΔW 在后续模块计算 |

精简后的三个组成部分为：

| 名称 | 功能 |
| --- | --- |
| `WritebackConfig` | 保存逐层 λ、求解精度、Q 存储精度和设备，四项参数的默认值沿用原实现 |
| `stable_frobenius_norm(value)` | 缩放后计算 Frobenius 范数，原计算保持不变，继续供优化、合并和接受模块调用 |
| `solve_writeback_factor(keys, keep, ridge, settings)` | 构造 H，分解 H=LLᵀ，解 HX=K，再返回指定存储精度、连续布局的 CPU Q；Q 不参与梯度 |

原 `WritebackConfig.check()` 用于配置合法性检查，`relative_residual()` 用于方程残差核对，`WritebackSolveError` 用于附带诊断报告的异常包装，均已移除。耗时、内存、谱尺度、四次方程残差和阶段报告也已删除；Cholesky 无法分解时由 PyTorch 直接报错，不自动调整 λ 或加入 jitter。

`p3` 配置现在只接受 `ridge_by_layer`、`compute_dtype`、`storage_dtype`、`device`；默认全流程配置无需修改。`solve_writeback_factor` 现在只返回 Q，调用方已同步，不保留旧报告返回值。

本轮 22 项相关测试全部通过，无跳过，包含 CPU/CUDA：对照提交 `347f0cd` 中的旧求解器，覆盖不同事实数、float32/float64 求解与存储，Q 逐位一致；独立核对 HX=K、QH=Kᵀ、公式（6）的唯一最小值及事实排列；既有小模型的 R、最终权重、优化轨迹和接受/回退结果保持一致。共享范数与 H 的释放也已核对，未运行完整 8B 实验。测试继续仅保留本地。

## 候选网络与残差优化：功能、函数与公式

`candidate.py` 定义由 R 控制的真实候选网络，`optimize.py` 在该网络上计算目标与梯度，选择最佳 R。两者属于 P4；实际权重合并仍由 P5 完成。

核对结论：在当前常驻模型、合法目标层及 Q/R 精度一致的输入前提下，原实现和精简后的数学主线均与《最终逻辑 V1.0》第六、七节对齐。文档允许的保持训练选择中，本项目继续采用最初 theta_0 到候选模型的完整词表 KL；Adam、预算和检查点沿用既定配置。此处的最佳 R 是有限预算内的较优检查点，不表示整网全局最优。

| 公式/步骤 | 数学含义 | 实现对应 |
| --- | --- | --- |
| （2）（3） | $F=\sum_{i,t,j}w_{i,t,j}[-\log p_\theta(y_{i,j}\mid x_{i,t})]$ | 固定监督位置的交叉熵直接乘原全局权重求和，微批不重新平均 |
| （10） | $J(R)=F(\theta(R))+\beta L_{\mathrm{keep}}(\theta(R))+\tfrac12\sum_\ell\rho_\ell\lVert R_\ell\rVert_F^2$ | 编辑损失、可选完整词表 KL、逐层残差正则 |
| （11） | $z=(W_b+RQ)k+b=W_bk+b+R(Qk)$ | 在目标线性层的所有位置和每次实际调用上加入分支；偏置沿用基准输出 |
| （12） | $\nabla_{R_\ell}J=(\nabla_{\widetilde W_\ell}E)Q_\ell^\top+\rho_\ell R_\ell$ | 数据损失经过所有编辑层联合反传，每个完整优化步仅加一次正则梯度 |
| 有限步选择 | $R^{(0)}=0$，选择有限、非零且 $J(R^*)<J(0)$ 的最佳预定检查点 | 保留严格比较和原检查点顺序；无合格候选时返回 None |
