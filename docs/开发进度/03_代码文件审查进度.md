## 本轮发现与修复

| 问题 | 修复 | 核验证据 |
| --- | --- | --- |
| 主体定位误拒绝字节拆分和带空格的 token，且未识别重叠出现的主体文本 | 按字符覆盖定位主体，允许合法重叠偏移及边缘合并；拒绝缺口、错序和歧义主体 | 两个旧实现失败用例修复后通过；另有缺口和重叠文本歧义测试 |
| 空答案位置、重复 mask 或窗口外 mask 可能进入状态计算 | 明确非空、有序、唯一的位置合同，核对完整输入中的实际 mask | 人工异常轨迹回归通过 |
| 筛选只核对事实 ID，未绑定探针和文件来源；公式核验失败仍可写出监督 | 产物升级 `p1.1`，核对版本、配置/文件摘要、事实与探针顺序；通过公式核验后才写出监督 | 配置变动、文件变动、探针错配、报告错配及失败门槛测试通过 |
| 已有运行在加载模型后才报错，模型加载失败没有运行诊断，重放固定取前几个事实 | 提前保留独立目录，记录失败阶段及事实，按固定种子抽样重放 | 重复运行、加载失败和重放失败回归通过；抽样逻辑完成静态核对 |
| logits 转 float32 后再取摘要可能丢失原始精度；前向依赖默认返回类型 | 摘要覆盖原始 dtype、shape 和字节；前向显式 `return_dict=True` | 原始精度摘要、捕获/清理 hook、权重恢复、采样重放 CPU 测试均通过 |
