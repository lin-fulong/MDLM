# 二、先明确整个算法解决的两个不同问题

给定编辑事实：

\[ \mathcal D_{\mathrm{edit}} = \{(q_i,s_i,r_i,a_i^*)\}_{i=1}^{N}, \]

目标是修改指定模块权重，使模型以后在**不接收新答案提示**时，也能够表达目标新事实，并尽量保持不应改变的行为。编辑输入、正式生成输入、裁判参考必须分开。 01_扩散知识编辑数据集构建

整个算法分成两个相互连接的数学问题：

|问题|数学形式|解决什么？|
|---|---|---|
|**条件化权重写回**|$\min_D\Phi(D\mid R)$|给定残差 $R$，怎样得到合适的权重增量？|
|**真实模型残差优化**|对 $J(R)$ 进行有限步优化|什么样的残差，能改善模型的新知识预测？|

前者推出：

\[ \boxed{\Delta W(R)=RQ.} \]

后者在固定 $Q$ 后，寻找候选：

\[ \boxed{R^*.} \]

最终才有：

\[ \boxed{\Delta W=R^*Q.} \]

**因此，不是先凭空指定一个最终残差，也不是直接对整个深层模型求闭式最优解。**原文将闭式性质限定于“给定残差后的线性写回”。 03_模型方案文档

# 三、公式（1）～（3）：从真实状态建立编辑监督

## 3.1 采集并固定去噪输入

本轮开始时：

\[ \theta_b=\theta_{\mathrm{acc}}. \]

用本轮基准模型从受控短答案窗口的全 mask 初态自主采样，保存每次前向前的完整输入：

\[ x_{i,t}. \]

**新答案用于随后筛选和计算损失，不回填采样轨迹。**去重必须依据实际完整输入，而不只是可见文本。 01_算法文档

## 3.2 公式（1）：兼容状态筛选

\[ \boxed{ \mathcal T_i = \left\{ t: \mathcal M_{i,t}\neq\varnothing,\quad x_{i,t,j}=a_{i,j}^* \quad \forall j\in\mathcal A_i\setminus\mathcal M_{i,t} \right\}. } \tag{1} \]

它要求同时满足：

**答案还有 mask；已揭示的答案部分与目标一致。**

合法非空目标的全 mask 初态保留，所以训练集合不会因为原模型尚不会新答案，就必然为空。冲突状态和终态另存诊断。

这条规则适用于文档规定的**不重新掩码的受控窗口**，不是所有采样器的通用可达性定理。本轮残差优化期间，状态和筛选结果固定。 粘贴的文本 (1)

## 3.3 公式（2）：单状态损失与整体编辑损失

\[ \boxed{ \begin{aligned} L_{i,t}(\theta) &= -\frac1{|\mathcal M_{i,t}|} \sum_{j\in\mathcal M_{i,t}} \log p_{\theta,j}(a_{i,j}^*\mid x_{i,t}),\\[3pt] F(\theta) &= \frac1N \sum_{i=1}^{N} \frac1{|\mathcal T_i|} \sum_{t\in\mathcal T_i}L_{i,t}(\theta). \end{aligned} } \tag{2} \]

归一顺序是：

\[ \boxed{ \text{一个状态内的剩余 mask} \rightarrow \text{同一事实的兼容状态} \rightarrow \text{全部事实}. } \]

## 3.4 公式（3）：展开每个位置的全局权重

\[ \boxed{ F(\theta) = -\sum_{i=1}^{N} \sum_{t\in\mathcal T_i} \sum_{j\in\mathcal M_{i,t}} \underbrace{ \frac1{N|\mathcal T_i||\mathcal M_{i,t}|} }_{w_{i,t,j}} \log p_{\theta,j}(a_{i,j}^*\mid x_{i,t}). } \tag{3} \]

因此，每条事实总权重都是：

\[ \frac1N. \]

不能把所有状态直接混在一起平均，否则状态较多的事实会自动获得更高权重。

**这一阶段只建立监督目标，尚未计算任何权重更新。**而且 $F$ 是固定状态上的短答案代理损失，不是自由生成完整回答的精确序列似然。 粘贴的文本 (1)

# 四、公式（4）～（5）：准备参考键与保持统计

## 4.1 公式（4）：参考键矩阵

默认每条事实、每个编辑模块，从本轮基准模型的全 mask 初态中，提取：

> 主体最后一个 token 位置处，目标 FFN 输出线性层的实际输入。

记为：

\[ k_{i,\ell}^{\mathrm{ref}}. \]

按事实列堆叠：

\[ \boxed{ K_\ell = [k_{1,\ell}^{\mathrm{ref}},\ldots,k_{N,\ell}^{\mathrm{ref}}] \in \mathbb R^{d_{\mathrm{in},\ell}\times N}. } \tag{4} \]

这不是答案 embedding，也不是注意力 Key。

**多个去噪状态用于监督；默认每条事实只有一列参考键。**这是当前方案的组织方式，不是所有扩散知识编辑都必须遵守的理论结论。 粘贴的文本 (1)

## 4.2 公式（5）：保持统计及其作用

原文规定：

\[ C_\ell=C_\ell^\top\succeq0, \]

且必须从目标扩散模型的保持输入与掩码上下文中重新提取。

其一般形式可以表示为：

\[ \boxed{ \begin{aligned} C_\ell &= \sum_m\omega_{\ell,m}u_{\ell,m}u_{\ell,m}^\top,\\ \operatorname{tr}(D_\ell C_\ell D_\ell^\top) &= \sum_m\omega_{\ell,m}\|D_\ell u_{\ell,m}\|_2^2, \qquad \omega_{\ell,m}\ge0. \end{aligned} } \tag{5} \]

第二行来自：

\[ \operatorname{tr} (Duu^\top D^\top) = \operatorname{tr}[(Du)(Du)^\top] = \|Du\|_2^2. \]

所以：

> **如果权重增量 $D$ 在保持输入激活 $u$ 上造成较大的局部输出变化，就会付出更大的保持代价。**

需要保留三个边界：

- $C$ 是未中心化二阶统计，不应无说明地改成去均值协方差。
- $\omega$ 已可包含保持尺度，原文没有要求这些权重必须总和为 1。
- 具体语料、mask、位置、权重和归一方法仍需配置；上述式子只是通用展开。

它约束固定保持激活上的线性扰动，不保证整个模型所有旧知识不变。 粘贴的文本 (1)

# 五、公式（6）～（9）：从软拟合问题推导固定因子 $Q$

## 5.1 为什么要拟合 $DK\approx R$？

暂时省略层标。

基准权重在参考键上的线性输出是：

\[ W_bK. \]

给定残差 $R$，相应目标定义为：

\[ W_bK+R. \]

加入权重增量 $D$ 后，实际输出是：

\[ (W_b+D)K. \]

二者之差：

\[ (W_b+D)K-(W_bK+R)=DK-R. \]

因此：

\[ \boxed{ \text{让更新后的参考输出接近目标} \Longleftrightarrow DK\approx R. } \]

固定偏置在比较中抵消，所以这里讨论去偏置的线性输出。

## 5.2 公式（6）：条件化软拟合目标

\[ \boxed{ \begin{aligned} \min_{D_\ell}\Phi_\ell(D_\ell\mid R_\ell) ={}& \frac12\|D_\ell K_\ell-R_\ell\|_F^2\\ &+\frac12\operatorname{tr}(D_\ell C_\ell D_\ell^\top)\\ &+\frac{\lambda_\ell}{2}\|D_\ell\|_F^2, \qquad \lambda_\ell>0. \end{aligned} } \tag{6} \]

三项分别负责：

\[ \text{目标拟合} + \text{局部保持} + \text{权重增量正则}. \]

**此时固定 $R$，只求 $D$。**这一步是为了建立“残差怎样转换为权重增量”的映射。

该目标与原迁移文档的 MEMIT 软拟合核相对应，额外的 ridge 是本项目明确加入的实现选择。 02_自回归模型迁移文档 02_自回归模型迁移文档

## 5.3 公式（7）：对 $D$ 求导，得到正规方程

由于 $C=C^\top$：

\[ \nabla_D\frac12\|DK-R\|_F^2=(DK-R)K^\top, \]\[ \nabla_D\frac12\operatorname{tr}(DCD^\top)=DC, \]\[ \nabla_D\frac{\lambda}{2}\|D\|_F^2=\lambda D. \]

其中保持项可通过微分识别：

\[ \begin{aligned} d\Phi_{\mathrm{keep}} &= \frac12\operatorname{tr} \left[(dD)CD^\top+DC(dD)^\top\right]\\ &= \operatorname{tr}\left[(DC)^\top dD\right]. \end{aligned} \]

因此其梯度为 $DC$。

将三项相加，并令梯度为零：

\[ (DK-R)K^\top+DC+\lambda D=0. \]

整理：

\[ \boxed{ D_\ell \underbrace{ (C_\ell+K_\ell K_\ell^\top+\lambda_\ell I) }_{H_\ell} = R_\ell K_\ell^\top. } \tag{7} \]

## 5.4 公式（8）：证明 $H$ 正定

对任意非零输入向量 $\xi$：

\[ \boxed{ \begin{aligned} \xi^\top H_\ell\xi &= \xi^\top C_\ell\xi + \|K_\ell^\top\xi\|_2^2 + \lambda_\ell\|\xi\|_2^2\\ &\ge \lambda_\ell\|\xi\|_2^2 >0. \end{aligned} } \tag{8} \]

因此：

\[ H_\ell\succ0, \]

所以 $H_\ell$ 可逆。

正 ridge 是保证正定的充分条件；如果 $C+KK^\top$ 本来已经正定，不代表没有 ridge 就必然不可解。

### 为什么求出的解是唯一最小值？

设 $D^*$ 满足：

\[ D^*H=RK^\top. \]

对任意与 $D$ 同形的扰动 $S$，精确展开得到：

\[ \begin{aligned} &\Phi(D^*+S\mid R)-\Phi(D^*\mid R)\\ ={}& \left\langle (D^*K-R)K^\top+D^*C+\lambda D^*,S \right\rangle_F\\ &+\frac12\operatorname{tr}(SHS^\top). \end{aligned} \]

第一行内积中的矩阵就是：

\[ D^*H-RK^\top=0. \]

所以：

\[ \boxed{ \Phi(D^*+S\mid R)-\Phi(D^*\mid R) = \frac12\operatorname{tr}(SHS^\top) \ge \frac{\lambda}{2}\|S\|_F^2. } \]

只要 $S\neq0$，差值就严格大于零。

因此，**固定 $R$ 后，权重写回子问题有唯一全局最小解**。这是对原文正定性和严格凸结论的展开，不是对整网残差优化的保证。 粘贴的文本 (1)

## 5.5 公式（9）：预先计算固定因子

由正规方程：

\[ D^*(R)=RK^\top H^{-1}. \]

其中：

\[ K^\top H^{-1} \]

不依赖 $R$，所以定义：

\[ Q=K^\top H^{-1}. \]

实际不显式求逆，而是：

\[ \boxed{ H_\ell X_\ell=K_\ell, \qquad Q_\ell=X_\ell^\top, \qquad \Delta W_\ell(R_\ell)=R_\ell Q_\ell. } \tag{9} \]

验证其等价性：

\[ HX=K \Longrightarrow X^\top H^\top=K^\top. \]

由于 $H^\top=H$，且 $Q=X^\top$：

\[ QH=K^\top. \]

左乘 $R$：

\[ (RQ)H=RK^\top. \]

它满足原正规方程，由解唯一性：

\[ \boxed{D^*(R)=RQ.} \]

这一阶段的最终结果是：

\[ \boxed{ K,C,\lambda \rightarrow H \rightarrow X \rightarrow Q\text{ 固定}. } \]

*_此时尚未求出最终 (R^_)，但已经知道任何 $R$ 应该怎样转换成权重增量。**正定性也不意味着有限精度求解没有风险，仍需检查求解误差、谱尺度和有限性。 粘贴的文本 (1) 01_算法文档

# 六、公式（10）～（11）：用真实候选模型决定残差

## 6.1 公式（10）：多层残差联合优化目标

\[ \boxed{ \begin{aligned} \theta(R) &= \theta_b\oplus\{R_\ell Q_\ell\}_{\ell\in\mathcal L},\\ J(R) &= F(\theta(R)) + \beta L_{\mathrm{keep}}(\theta(R)) + \frac12\sum_{\ell\in\mathcal L} \rho_\ell\|R_\ell\|_F^2. \end{aligned} } \tag{10} \]

其中：

\[ \beta\ge0,\qquad \rho_\ell>0. \]

本轮固定：

\[ \theta_b,\quad x_{i,t},\quad K_\ell,\quad C_\ell,\quad Q_\ell, \]

只优化：

\[ R=\{R_\ell\}_{\ell\in\mathcal L}. \]

三个目标分别要求：

|项|作用|
|---|---|
|$F(\theta(R))$|提高新答案的预测概率|
|$\beta L_{\mathrm{keep}}(\theta(R))$|限制保持训练输入上的变化|
|$\frac12\sum_\ell\rho_\ell\|R_\ell\|_F^2$|限制残差变量规模|

这里的 $\rho_\ell$ 与前面的 $\lambda_\ell$ 不同：前者惩罚 $R_\ell$，后者出现在条件化权重增量 $D_\ell$ 的二次问题中。 粘贴的文本 (1)

### 保持训练损失还需要确认什么？

原《算法文档》允许训练保持项采用与开发保持相同方向的 KL，但**训练保持输入与开发输入分开**，参照最初模型 $\theta_0$。 01_算法文档

这一允许选项可以展开为：

\[ L_{\mathrm{keep}}^{\mathrm{KL}}(\theta) = \sum_{h,j}b_{h,j}^{\mathrm{tr}} D_{\mathrm{KL}} \left( p_{\theta_0,j}(\cdot\mid u_h^{\mathrm{tr}}) \Vert p_{\theta,j}(\cdot\mid u_h^{\mathrm{tr}}) \right), \]

其中：

\[ b_{h,j}^{\mathrm{tr}}\ge0, \qquad \sum_{h,j}b_{h,j}^{\mathrm{tr}}=1. \]

上标 $\mathrm{tr}$ 表示保持训练用途。

**这是原文允许的选项，不是在此代为确定最终训练配方。**是否启用、采用哪些数据和位置权重，仍需配置。若 $\beta=0$，不计算训练保持项，但仍需执行开发保持验收。

## 6.2 公式（11）：真实候选前向

对当前候选模型的实际模块输入 $k$：

\[ \boxed{ \begin{aligned} z_{\ell,p} &= (W_{b,\ell}+R_\ell Q_\ell)k+b_\ell\\ &= W_{b,\ell}k+b_\ell+R_\ell(Q_\ell k). \end{aligned} } \tag{11} \]

这说明两种实现代数等价：

\[ \boxed{ \text{使用候选权重} \quad=\quad \text{基准模块计算＋临时因子分支}. } \]

但必须满足：

**临时分支覆盖该权重实际作用的全部调用位置，而不是只在主体位置加入向量。**

另外：

\[ K_\ell,Q_\ell\text{ 固定} \quad\neq\quad k\text{ 固定}. \]

前层残差变化会影响后层实际输入。因此所有编辑层应在同一个候选网络中生效，保留真实跨层计算。 粘贴的文本 (1)

# 七、公式（12）：计算梯度并优化得到 $R^*$

## 7.1 从有效权重变化推导残差梯度

定义：

\[ E(R)=F(\theta(R))+\beta L_{\mathrm{keep}}(\theta(R)), \]\[ \widetilde W_\ell=W_{b,\ell}+R_\ell Q_\ell. \]

因为 $Q_\ell$ 固定：

\[ d\widetilde W_\ell=(dR_\ell)Q_\ell. \]

整个数据损失的微分为：

\[ \begin{aligned} dE &= \sum_{\ell\in\mathcal L} \operatorname{tr} \left[ (\nabla_{\widetilde W_\ell}E)^\top (dR_\ell)Q_\ell \right]\\ &= \sum_{\ell\in\mathcal L} \operatorname{tr} \left[ \bigl((\nabla_{\widetilde W_\ell}E)Q_\ell^\top\bigr)^\top dR_\ell \right]. \end{aligned} \]

根据矩阵梯度定义：

\[ dE=\sum_\ell \operatorname{tr} \left[(\nabla_{R_\ell}E)^\top dR_\ell\right], \]

得到：

\[ \nabla_{R_\ell}E = (\nabla_{\widetilde W_\ell}E)Q_\ell^\top. \]

再加入：

\[ \nabla_{R_\ell} \frac{\rho_\ell}{2}\|R_\ell\|_F^2 = \rho_\ell R_\ell, \]

得到：

\[ \boxed{ \nabla_{R_\ell}J = (\nabla_{\widetilde W_\ell}E)Q_\ell^\top + \rho_\ell R_\ell. } \tag{12} \]

这与原文公式（12）一致。这里对多层总微分显式求和，避免把单层局部表达误解为整个总微分。 粘贴的文本 (1)

## 7.2 从一次模块调用理解反向传播

若模块输出梯度为：

\[ e=\frac{\partial E}{\partial z}, \]

则该调用对残差的直接梯度贡献为：

\[ \boxed{e(Qk)^\top.} \]

传给模块输入的梯度是：

\[ \boxed{ \frac{\partial E}{\partial k} = (W_b+RQ)^\top e. } \]

所以：

> **冻结基准权重，不等于切断经过基准模块的梯度。**

实现可以直接沿因子分支累计 $R$ 的梯度，不要求先显式保存完整的候选权重梯度矩阵。

## 7.3 有限步优化

原文规定：

\[ \boxed{R_\ell^{(0)}=0.} \]

因此初始候选模型等于本轮基准：

\[ \theta(R^{(0)})=\theta_b. \]

用普通梯度下降示意更新规则：

\[ \boxed{ R_\ell^{(n+1)} = R_\ell^{(n)} - \eta_n\nabla_{R_\ell}J(R^{(n)}). } \]

这只是说明优化器如何使用梯度，实际优化器、学习率和预算仍需配置。

一个完整优化步中：

|顺序|操作|
|---|---|
|1|清空残差梯度，保持本步残差数值不变|
|2|逐微批重放兼容状态，计算全局加权编辑梯度|
|3|启用保持项时，按其固定权重累计保持梯度|
|4|残差正则每个完整优化步只计算一次|
|5|检查梯度有限性，统一更新各层残差|
|6|在预定检查点记录候选和训练目标|

最后按预定规则选取有限、非零且：

\[ J(R^*)<J(0) \]

的较优候选；没有合格候选则本轮失败。

**$R^*$ 不必是最后一次迭代，也不表示已达到整网全局最优。**微批可以释放计算图，但不能切断同一次候选前向中的跨层梯度。 01_算法文档

# 八、公式（13）～（14）：生成实际增量并解释软拟合误差

## 8.1 公式（13）：辅助目标与实际更新

\[ \boxed{ V_\ell^*=W_{b,\ell}K_\ell+R_\ell^*, \qquad \Delta W_\ell=R_\ell^*Q_\ell. } \tag{13} \]

两者分工不同：

|数学量|作用|
|---|---|
|$V_\ell^*$|定义固定参考键上的去偏置辅助目标输出|
|$\Delta W_\ell$|真正准备加入模型权重的候选增量|

$V_\ell^*$ 不直接写入参数，也不是额外给出的完整答案标签。当前主线先通过真实候选网络选出 $R^*$，再据此定义 $V^*$。 粘贴的文本 (1)

## 8.2 公式（14）：实际参考输出与目标之间的差

暂取写回步长为 1：

\[ W_\ell'=W_{b,\ell}+R_\ell^*Q_\ell. \]

则：

\[ \begin{aligned} W_\ell'K_\ell-V_\ell^* &= (W_{b,\ell}+R_\ell^*Q_\ell)K_\ell - (W_{b,\ell}K_\ell+R_\ell^*)\\ &= R_\ell^*Q_\ell K_\ell-R_\ell^*. \end{aligned} \]

因此：

\[ \boxed{ (W_{b,\ell}+\Delta W_\ell)K_\ell-V_\ell^* = R_\ell^*(Q_\ell K_\ell-I_N). } \tag{14} \]

它量化的是：

> **固定参考键上的局部软拟合误差。**

它不是最终回答的语义误差。

# 九、公式（15）：构造实际合并候选

\[ \boxed{ \begin{aligned} W_{\alpha,\ell} &= W_{b,\ell}+\alpha\Delta W_\ell,\\ \theta_\alpha &= \theta_b\oplus \{\alpha\Delta W_\ell\}_{\ell\in\mathcal L}. \end{aligned} } \tag{15} \]

这里：

\[ \Delta W_\ell=R_\ell^*Q_\ell. \]

$\alpha$ 来自预定有限正序列，全部编辑模块共用一个值。

**每次试步都从本轮基准重建：**

\[ W_{\alpha_j,\ell} = W_{b,\ell}+\alpha_j\Delta W_\ell. \]

不是：

\[ W_{\alpha_j,\ell} = W_{\alpha_{j-1},\ell}+\alpha_j\Delta W_\ell. \]

后者会累加不同试步，改变算法。

合并前后还要检查相同输入、相同缩放下的等价性：

\[ \boxed{ (W_b+\alpha R^*Q)k+b = W_bk+b+\alpha R^*(Qk). } \]

实际合并后关闭临时分支，避免重复施加增量，并在预定数值容差内检查 logits 一致性。原伪代码先执行一致性检查，再进行公共试步和开发验收。 01_算法文档

需要注意，缩放后的 $\alpha\Delta W$ 一般不再是固定原残差 $R^*$ 的同一个二次问题的最优解。此时是在**实际模型层面选择可接受的候选**，不是重新证明局部二次最优性。

# 十、公式（16）～（18）：开发验收与回退

## 10.1 公式（16）：保持分布漂移

\[ \boxed{ G_{\mathrm{dev}}(\theta) = \sum_{h,j}b_{h,j} D_{\mathrm{KL}} \left( p_{\theta_0,j}(\cdot\mid u_h) \Vert p_{\theta,j}(\cdot\mid u_h) \right). } \tag{16} \]

其中：

\[ b_{h,j}\ge0, \qquad \sum_{h,j}b_{h,j}=1. \]

$u_h$ 是固定开发保持输入，$j$ 是预先选定的合法 mask 读出位置。

比较双方必须使用**相同输入和位置**，不是直接比较两条不同的自由生成轨迹。

这个指标的参照始终是最初模型：

\[ \theta_0. \]

## 10.2 公式（17）：KL 与累计参数变化

\[ \boxed{ \begin{aligned} D_{\mathrm{KL}}(P\Vert Q) &= \sum_{v\in\mathcal V} P(v)\log\frac{P(v)}{Q(v)},\\[4pt] U(\theta) &= \frac{ \sqrt{ \sum_{\ell\in\mathcal L} \|W_\ell(\theta)-W_{0,\ell}\|_F^2 } }{ \max\left\{ \sqrt{ \sum_{\ell\in\mathcal L} \|W_{0,\ell}\|_F^2 }, \epsilon \right\} }. \end{aligned} } \tag{17} \]

这里 KL 定义中的 $P,Q$ 是一般概率分布，**不是固定写回矩阵 $Q_\ell$**。

$U$ 衡量的是：

\[ \frac{\text{当前权重与最初权重的整体净变化}} {\text{最初这些权重的整体规模，带分母下界}}. \]

它不是残差范数，也不是历次更新范数的简单相加。

这两个指标的数学定义及最初模型参照，原文已经明确。 01_算法文档

## 10.3 公式（18）：三个条件必须同时通过

\[ \boxed{ \begin{cases} F_{\mathrm{dev}}(\theta_\alpha) \le F_{\mathrm{dev}}(\theta_b)-\delta,\\[4pt] G_{\mathrm{dev}}(\theta_\alpha)\le\tau_G,\\[4pt] U(\theta_\alpha)\le\tau_U. \end{cases} } \tag{18} \]

各项作用如下：

|条件|检查内容|参照|
|---|---|---|
|$F_{\mathrm{dev}}$|新知识开发损失至少改善 $\delta$|本轮基准 $\theta_b$|
|$G_{\mathrm{dev}}$|保持输入上的完整词表分布漂移受控|最初模型 $\theta_0$|
|$U$|指定权重的累计相对变化受控|最初权重 $W_0$|

$F_{\mathrm{dev}}$ 是固定开发编辑输入上的短答案损失，不是总训练目标 $J$，也不是最终生成准确率。开发输入、对齐和归一协议需要预先确定。

这些条件不能通过加权求和互相抵消：编辑损失非常好，也不能抵消保持漂移超标。

还必须通过数值有限性、参数完整性、逐层更新和前向一致性检查。 粘贴的文本 (1)

## 10.4 接受与回退逻辑

按预定顺序尝试有限个 $\alpha$：

**全部条件通过：**接受该候选，更新 $\theta_{\mathrm{acc}}$，停止本次试步。

**未通过：**恢复本轮基准，尝试下一个 $\alpha$。

**全部试步失败：**保留上一接受模型，停止外轮。

不能不断缩小 $\alpha$ 就认为总能通过，因为更新太小可能达不到最低编辑改善量 $\delta$。原文没有保证一定存在合格步长。 01_算法文档 01_算法文档

## 最终，用一条数学链概括整套算法

\[ \boxed{ \begin{gathered} \text{编辑事实与本轮基准模型}\\ \Downarrow\\ \text{真实兼容状态} \longrightarrow F(\theta)\\ \text{基准输入激活} \longrightarrow K_\ell,C_\ell\\ \Downarrow\\ H_\ell=C_\ell+K_\ell K_\ell^\top+\lambda_\ell I\\ H_\ell X_\ell=K_\ell,\qquad Q_\ell=X_\ell^\top\\ \Downarrow\\ \theta(R)=\theta_b\oplus\{R_\ell Q_\ell\}\\ \Downarrow\\ \text{通过 }J(R)\text{ 和公式（12）有限步优化}\\ \Downarrow\\ R^*\longrightarrow\Delta W_\ell=R_\ell^*Q_\ell\\ \Downarrow\\ \theta_\alpha=\theta_b\oplus\{\alpha\Delta W_\ell\}\\ \Downarrow\\ \text{合并一致性检查、开发验收、接受或回退}\\ \Downarrow\\ \text{固定最终权重，独立自由生成与评价}. \end{gathered} } \]

**整套数学逻辑最重要的分界只有一个：**

\[ \boxed{ \underbrace{\min_D\Phi(D\mid R)}_{\text{确定“给定残差怎样写回”}} \quad\longrightarrow\quad \underbrace{\text{有限优化 }J(R)}_{\text{确定“选择哪个残差”}} \quad\longrightarrow\quad \underbrace{\text{实际合并、验收与测试}}_{\text{检验“是否值得接受、是否真的有效”}}. } \]

**条件化写回可以有严格的唯一最优解；残差选择仍依赖真实模型优化；最终知识编辑效果则必须通过独立生成验证。三者共同构成当前算法，而不能相互替代。**
